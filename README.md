# Quire

Turn a digital book into printable sheets, covers and binding instructions. By [ALLUSIONS](https://allusions.pages.dev/).

Download: **[Quire.exe](https://github.com/allusionsafk/quire-download/releases/latest/download/Quire.exe)** (version 1.2.1, Windows 10/11, 64-bit, about 78 MB)

No installer is needed. Save the file and double-click it.

If Windows shows "Windows protected your PC", click **More info**, then **Run anyway**. This appears because the app isn't code-signed.

Each release lists the file's SHA-256 checksum in `SHA256SUMS.txt`.

## New in 1.2.1
- Two-piece covers can print on photo paper that's glossy on one side only. Fold arrows, glue areas and short instructions are printed only on the parts the finished book hides, so the front, spine and back stay clean.
- A separate glue guide prints on plain paper: lay each cover piece face down on it to see where the glue goes and in what order.
- Choose "Two-piece printing" in the cover studio: one side (new) or both sides (the glue map printed on the back, as before).

## New in 1.2.0
For EPUB books:
- Book styles, page sizes from A6 to Royal (with trim marks), text and heading fonts, chapter heading styles, drop caps.
- Page numbers (i, ii, iii… then 1 at chapter 1) and running heads, left off blank, title and chapter-opening pages.
- Book parts you can tick: half title, title page, copyright page, dedication, epigraph, contents with real page numbers, acknowledgments, about the author, notes pages, colophon.
- Print only some chapters (from / to) with a volume name on the title page.
- A "What went into the book" report says what was added, what was skipped and why.

## New in 1.1.0
- Cover studio takes your own finished cover PDF (back on the left, front on the right), or a separate back cover.
- A search box for cover art, and a card showing the title and author Quire read from your book.
- Rotated PDF pages no longer print blank, and print files are much smaller.
- Quire stops before printing if the printer's own Booklet or Multiple Page setting is on.
